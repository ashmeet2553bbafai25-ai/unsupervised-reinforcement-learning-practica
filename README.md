# Unsupervised & Reinforcement Learning Practical

This repository contains a Python practical covering:

* **K-Means Clustering** for customer segmentation
* Customer grouping using **Monthly Spending** and **App Visits**
* Basic **Reinforcement Learning**
* Agent, Action, Environment and Reward
* Exploration vs Exploitation
* Simple delivery-route optimization example

## Technologies

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Google Colab

## Repository Structure

```text
part-a/
└── unsupervised-learning/
    └── Unsupervised_and_Reinforcement_Learning_Practical_Name.ipynb
```

## Objective

The practical demonstrates how machine learning can be used to discover customer groups and understand decision-making through rewards.

## Result

K-Means divides customers into 3 clusters, while the Reinforcement Learning example compares delivery routes based on their average rewards.
